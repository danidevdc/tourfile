# 📸 Captura de pantalla para el README

El README de la raíz usa **una sola imagen**, la pantalla de bienvenida:

| Archivo | Qué es |
|---|---|
| `inicio.png` | La pantalla "BIENVENIDO!" con los cinco accesos a módulos y el indicador de base de datos conectada. |

Guárdala aquí con ese nombre exacto y el README la muestra sola.

## Antes de guardarla

La captura de pantalla trae el correo del usuario en la barra superior.
**Bórralo o difumínalo**, porque el repositorio es público y ese correo queda
indexado por Google y por GitHub.

También conviene recortar el borde derecho: la captura tiene la barra de scroll
del navegador y algo de margen vacío. Un recorte a la altura del pie de página
(`© 2026 TourFile Generator...`) queda mejor.

## Formato

- **PNG**, menos de ~500 KB.
- **1600 px** de ancho o más para que se vea nítida en pantallas grandes.
- Sin barra del navegador ni fondo del escritorio.
