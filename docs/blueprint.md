# **App Name**: TourFileProcessor

## Core Features:

- File Upload: Allows the user to upload their monthly tourism program file.
- File Number Input: Input field to enter the specific file number (e.g., abcd12344).
- Guide Name Input: Input field for entering the tour guide's name.
- Data Extraction: Extracts relevant data from the uploaded file based on the provided file number, mirroring the functionality of the Python script.
- Excel Generation: Generates a new Excel file with the extracted data and fills in the tour guide's name where necessary. The filename follows the format: G.O. fecha del file - nombre del grupo del file - dato del guia - nro de file.
- Download Button: A button to download the generated Excel file.

## Style Guidelines:

- Primary color: Turquoise (#40E0D0) for a fresh and vibrant feel.
- Secondary color: Light Gray (#D3D3D3) for a soft and neutral background.
- Accent color: Soft Blue (#64B5F6) for highlighting key elements and interactive components.
- Body and headline font: 'Roboto' sans-serif for clear readability and a modern feel.
- Clean and intuitive layout with a focus on usability. Prioritize easy navigation and a straightforward user experience.
- Use simple, professional icons to represent actions like file upload and download.
